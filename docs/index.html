1. NASA coordinates + JPL Horizons ✓

At a precise lunar site and UTC time, compute Sun/Earth azimuth and elevation. Site04: 169 real NASA-calculated hourly records, Dec 1–8, 2026. Values are predictions, not actual mission measurements.

2. NASA LOLA terrain — pending verification

The elevation raster helps estimate the real terrain skyline. One Site04 elevation was audited, but horizon directions, distant terrain and reference conventions still require checks. Horizontal zero is not terrain horizon.

3. Mission Rescue — our innovation

Compare original plan vs delayed starts vs another site, explain all confirmed constraints and prioritize alternatives. Time margin is reported only after the continuous window's real physical end is established.

4. What we can claim today

Verified source acquisition and displayed Horizons angles for Site04; a programmed Rescue framework. Not yet verified: Site01 geometry, actual terrain horizon, electrical power, continuous Earth opportunity or a successful rescue recommendation.

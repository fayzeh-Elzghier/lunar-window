How to interpret time margin

Sampled reference slack measures how far a sampled passing run extends beyond the requested finish, when a later failing sample brackets its end. Dataset cutoffs return unknown. This does not establish a continuously validated physical window.

NASA LRO / LOLA

Actually used: local 5 m DEMs, a wider 80 m south-pole DEM sampled to ~300 km, and local total-height RMS error maps. The complete horizon and frame alignment remain unverified.
